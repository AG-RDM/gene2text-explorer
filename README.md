# gene2text Explorer

[![Deploy gene2text Explorer](https://github.com/AG-RDM/gene2text-explorer/actions/workflows/deploy-pages.yml/badge.svg)](https://github.com/AG-RDM/gene2text-explorer/actions/workflows/deploy-pages.yml)

Public scientist-facing beta for exploring transcriptomic dataset relationships generated by the private gene2text research pipeline.

## Published content

- `index.html`: project context, scoring method and interpretation guidance
- `styles.css`: responsive visual design
- `graph.html`: self-contained interactive graph with embedded public GEO-derived results

The site intentionally excludes pipeline source code, API credentials, raw expression data, local paths, manuscripts and publication PDFs.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` publishes the site from `main`.

Expected URL:

```text
https://ag-rdm.github.io/gene2text-explorer/
```

The graph is an exploratory research prototype. Its model-generated scores are not validated biological ground truth and must not be used as clinical evidence.
